# handoff

文脈が埋まってきたら知らせ、引き継ぎメモを書いて新しい会話へ渡すプラグイン。

## ✨ 機能

| できること | 中身 |
| --- | --- |
| 勧める | 返答のたびに文脈を測り、`threshold` を超えたら右のペインを開く。「あとで」かペインを閉じると、その会話では勧めない |
| 書く | 会話を読み、書き換えたファイルを集めて、モデルに引き継ぎメモを書かせる |
| 確かめる | 20 行を超えたら、1 回だけ削らせる。リポジトリの `.gitignore` にメモのパスが無ければ足す |
| 渡す | 「新しい会話で始める」で `/clear` し、入力欄にメモを入れる。コピー・開く・書き直すのボタンもある |
| 失敗を知らせる | モデルが答えない時や書き込めない時は、トーストで知らせて「やり直す」を出す |

## 📦 入れ方

```sh
/plugin install handoff --marketplace yossibank/claude-plugins
```

## 🚀 使い方

文脈の量によらず、すぐに書く時はコマンドを使う。

| コマンド | 中身 |
| --- | --- |
| `/handoff` | 右のペインを開いて、引き継ぎメモを書く。できた後は、書き直さずにペインを開き直す |

## 🖥️ ペイン

上から次の順に並べる。ボタンは枠で囲み、右端のキー 1 つでも押せる。

| 場所 | 出すもの |
| --- | --- |
| 一番上 | リポジトリ、ブランチ、前のメモが何時間前か |
| 見出し | 状態と、要約まで残りのトークン・経過時間と目安・メモの行数と字数のどれか |
| タイル | 文脈の割合、会話の件数とターン、書き換えたファイルの件数とその未 commit の `+追加 −削除`、メモの行数 |
| いま区切ると | 勧める時だけ。次の会話の文脈と、1 回の要求の入力がどれだけ軽くなるかの見積もり |
| 工程 | 4 段の進みの棒と、かかった時間 |
| 次にすること | 完成した時だけ。メモの `次：` と `未検証：` |
| メモ | 完成した時だけ。全文と、作るのに使ったトークン |

| キー | ボタン |
| --- | --- |
| `h` | 引き継ぐ |
| `l` | あとで |
| `n` | 新しい会話で始める |
| `c` | コピー |
| `e` | 開く |
| `r` | 書き直す・やり直す |
| `x` | 閉じる・隠す |

[ルートの README の入れ方](../../README.md#-入れ方)

## 📏 メモの形

見出しは `# 引き継ぎ` の 1 つだけにし、その下に項目を 1 行ずつ並べる。中身の無い項目は書かない。

| 項目 | 書くこと |
| --- | --- |
| 目的 | 何を終えれば完了か |
| 決めたこと | 理由が要るものだけ |
| 次 | 次にすることを、する順に番号付きで |
| 触ったファイル | パスだけ |
| 未検証 | 確かめていないこと |

## 🔧 設定

| 名前 | 中身 |
| --- | --- |
| `threshold` | 勧める埋まり具合（%）。分母は session-dashboard の Context と同じ、要約に入る手前までの窓 |
| `handoffPath` | メモの置き場。リポジトリの一番上からの相対パスか、絶対パス |

[既定の値](.claude-plugin/plugin.json)
