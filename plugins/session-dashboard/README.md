# session-dashboard

セッションの状態を、右の pane と入力欄の上に出す Claude Code のプラグイン。

## ✨ 出すもの

| 表 | 中身 |
| --- | --- |
| Claude | モデル、費用、版 |
| リポジトリ | ブランチ、差分（`+追加 -削除 ?未追跡`） |
| Limit | 利用の上限ごとの割合と、戻るまでの時間 |
| Context | 文脈の埋まり具合、種類ごとの量、S〜D の評価、キャッシュが切れるまでの時間 |
| Next | handoff の `次：` の項目 |
| Now | 今の作業、動いているツール、サブエージェントの木 |
| Session | 経った時間、ターン、呼び出しの数、1 時間あたりの費用 |
| Tasks | 作業の一覧と済みの数 |
| Files | 書き換えたファイルと回数 |

| 場所 | 中身 |
| --- | --- |
| 右の pane | 上の表をすべて出す |
| 入力欄の上 | pane を閉じている間は、`│` で区切った 1 行。作業中は今の作業の 1 行を足す |

## 🚀 コマンド

| コマンド | 中身 |
| --- | --- |
| `/session-dashboard` | 右の pane を開く |

## 🖥️ Now の木

| 行 | 中身 |
| --- | --- |
| 作業 | 作業中の Task。なければ応答の最初の行 |
| 実行 | 動いているツールと経った秒数。重なっていれば `Agent ×3 · 2m14s` のようにまとめる |
| 木 | サブエージェントごとに、種類・題・経過。動いている間は 2 行目に今のツールとツールの回数 |

| 場面 | 見た目 |
| --- | --- |
| 終わった | 済みの印と経過 |
| 失敗・停止 | 失敗の印と経過 |
| 残す間 | 終わったものは、次のメインの `turn.start` まで残す |
| 5 本を超えた | 動いているものを先に残し、残りは「ほか N 本」 |
| メインで重なったツール | 同時の Read なども、同じ木に並べる |
| 幅が狭い | 右の列（経過・回数）から落とす |

## 🔧 設定

| 設定 | 既定 | 中身 |
| --- | --- | --- |
| `cacheMinutes` | `60` | プロンプトキャッシュの寿命の分数。`5` か `60` |
| `handoffPath` | `.claude/handoff.md` | 引き継ぎメモの置き場 |

## ⚠️ Next の読み方

| 決まり | 中身 |
| --- | --- |
| 形 | handoff の `- 次：1. … 2. …` の行。次の行から字下げして続く形も読む |
| 読む時 | セッションの始まりと `/clear` の時だけ |
| 消える時 | 読んだ後に handoff が書き換わると、Next は消える |
