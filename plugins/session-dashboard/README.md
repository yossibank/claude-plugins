# session-dashboard

セッションの状態を、右の pane と入力欄の上に出す Claude Code のプラグイン。

## ✨ 出すもの

| 表 | 中身 |
| --- | --- |
| Claude | モデル、費用、版 |
| リポジトリ | ブランチ、差分（`+追加 -削除 ?未追跡`）、upstream との差、最後の commit |
| Limit | 利用の上限ごとの割合と、戻るまでの時間。下の罫線に、今のペースの予測 |
| Context | 文脈の埋まり具合、種類ごとの量、ターンごとの推移、自動の要約までの残り、S〜D の評価、キャッシュが切れるまでの時間 |
| Tokens | セッションで使った入力と出力の合計、キャッシュから読めた割合 |
| Session | 経った時間、ターン、呼び出しの数、1 時間あたりの費用、ターンの平均と直近の時間、よく使ったツールと失敗の数 |
| Daily | このマシンの全セッションを足した、今日と直近 7 日の費用とトークン、1 日あたりの平均、日ごとの棒 |

行の読み方は次のとおり。

| 行 | 中身 |
| --- | --- |
| `sync │ ↑2 ↓1` | upstream との差。`↑` はまだ push していない commit、`↓` はまだ取り込んでいない commit。揃っていれば「同期済み」。upstream が無ければ出さない |
| `last │ 3h前 fix: 直す` | 最後の commit の、経った時間と題 |
| `予測 5h 109% · 7d 79%` | 今のペースのまま、戻る時刻まで使った時の割合。100% を超えると、戻る前に上限に届く。窓が 5% 進むまでは出さない |
| `推移 │ ▃▄▄▅ +10k/ターン` | メインのターンの終わりごとの文脈の量と、1 ターンで増える量の平均。2 ターン目から出す |
| `要約まで │ あと 88k · 約 9 ターン` | 自動の要約が始まるまでの残りと、今の増え方であと何ターンか。3 ターンを切ると赤くする。自動の要約を切っていれば出さない |
| `in │ 96k · 新規 16k` | 入力の合計と、そのうちキャッシュから読めなかった分。サブエージェントの分も足す |
| `cache │ ━━━━  83%` | 入力のうち、キャッシュから読めた割合。高いほど緑にする |
| `turn │ 平均 1m00s · 直近 30s` | メインのターンにかかった時間 |
| `tools │ Bash 12 · Read 8 · Edit 3 · 失敗 2` | よく使ったツールを多い順に 3 つと、失敗した呼び出しの数 |
| `today │ $2.41 · in 1.2M · out 38k` | 今日の費用と、入力・出力のトークン。このマシンの全セッションを足す。入力はキャッシュの読み書きも足す |
| `week │ $12.80 · in 6.0M · out 210k` | 今日までの直近 7 日の合計 |
| `avg │ $2.56/日 · 平均の 0.9 倍` | 直近 7 日の 1 日あたりの平均と、今日がその何倍か。平均は使った日だけで割る。平均より多ければ橙、少なければ緑にする |
| `days │ ▂▂ ▅▅ ▁▁ ██ ▃▃ ▄▄ ▃▃` | 直近 7 日の日ごとの費用の棒。下の行は曜日の字。右の端が今日で、色を変える。費用が分からない間は、トークンの数で比べる |

Daily の表の読み方は次のとおり。

| 決まり | 中身 |
| --- | --- |
| 日の区切り | ローカルの日付（`YYYY-MM-DD`）。日付をまたいだセッションは、増えた分を新しい日に足す |
| 足す時 | メインのターンの終わりと、セッションの始まり・`/clear`。ほかのセッションの分は、その時に読み直す |
| 残す日数 | プラグインの store に直近 14 日。古い日は消す |
| `/clear` | セッションの合計が 0 に戻っても、足した値は減らさない |
| 出さない時 | 直近 7 日に何も無い間は、表を出さない |

| 場所 | 中身 |
| --- | --- |
| 右の pane | 上の表をすべて出す |
| 入力欄の上 | pane を閉じている間は、`│` で区切った 1 行 |

今の作業とサブエージェントは [agent-progress](../agent-progress/README.md) に移った。

## 📦 入れ方

```sh
/plugin install session-dashboard --marketplace yossibank/claude-plugins
```

## 🚀 コマンド

| コマンド | 中身 |
| --- | --- |
| `/session-dashboard` | 右の pane を開く |

## 🔧 設定

| 設定 | 既定 | 中身 |
| --- | --- | --- |
| `cacheMinutes` | `60` | プロンプトキャッシュの寿命の分数。`5` か `60` |
