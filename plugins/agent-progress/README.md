# agent-progress

メインとサブエージェントが今していることを、動く Claude のアイコン付きのカードで右の pane に出す mod。

## ✨ 出すもの

| 場所 | 中身 |
| --- | --- |
| メインのカード | モデル・ターンの経過時間・今の作業・動いているツール・入力と出力のトークン。重なったツールは `Bash ×3` にまとめる |
| Running | 動いているサブエージェントの種類・モデル・経った時間・題・動いているツール・トークン・ツールの回数 |
| Finished | 終わったサブエージェント。最後のツールか、失敗・停止の印を出し、次のメインのターンで消す |
| Tasks | 済みの数と割合の棒、作業中の項目、印付きの一覧 |
| 入力欄の上 | pane を閉じている作業中だけ、今の作業とサブエージェントの数を 1 行で出す |

作業・題・ツールは切らずに、pane の幅で折り返して出す。トークンは、キャッシュから読んだ分と書いた分を入力に含める。

## 📦 入れ方

```sh
/plugin install agent-progress --marketplace yossibank/claude-plugins
```

## 🚀 コマンド

| コマンド | 中身 |
| --- | --- |
| `/agent-progress` | 閉じた pane を開き直す |

## 🖥️ アイコン

Claude Code の起動画面のロゴを、9 桁 × 3 行で描く。端末の面にだけ出し、ほかの面では文字のカードだけを出す。

| 状態 | 色 | 動き |
| --- | --- | --- |
| メインが作業中 | ロゴの色 | 立つ・かがむ・まばたき・かがむを 250ms ごとに回す |
| メインが待っている | 灰 | 止まる |
| サブエージェントが動いている | 起こした順に青・緑・ピンク・紫・水色 | メインと同じく回す |
| サブエージェントが終わった | その色のまま | 止まる |
| 失敗・停止した | 赤 | 止まる |
