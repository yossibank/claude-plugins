# agent-progress

メインとサブエージェントが今していることを、動く Claude のアイコン付きのカードで右の pane に出す mod。

## ✨ 出すもの

| 場所 | 中身 |
| --- | --- |
| メインのカード | モデル・ターンの経過時間・今の作業・終わったツールの履歴・動いているツール・入力と出力のトークン・ツールの回数と色分けした内訳。重なったツールは `Bash ×3` にまとめる。ターンが終わると、完了・中断・エラーとかかった時間を出す |
| 合計 | メインのカードの下に、全員分のトークン・ツールの回数・失敗の数 |
| Running | 動いているサブエージェントの種類・モデル・経った時間・題・発言の最初の行・終わったツールの履歴・動いているツール・トークン・ツールの回数と内訳 |
| Finished | 終わったサブエージェント。報告の最初の行（無ければ最後のツール）か、失敗・停止の印を出し、次のメインのターンで消す |
| Tasks | 済みの数と割合の棒、作業中の項目、印付きの一覧 |
| 入力欄の上 | pane を閉じている作業中だけ、今の作業・サブエージェントの数・作業の一覧の済みの数を 1 行で出す |

作業・題・ツールは切らずに、pane の幅で折り返して出す。トークンは、キャッシュから読んだ分と書いた分を入力に含める。

ツールの行の読み方は次のとおり。

| 行 | 中身 |
| --- | --- |
| `● Bash: テストを走らせる · 3s` | 動いているツールと、経った時間 |
| `✓ Read: hooks/view.ts:40-59` | 終わったツール。直近の 2 つ（動いているツールが無い時は 3 つ）を残す。1 秒を超えたら、かかった時間を添える |
| `✗ Edit: hooks/view.ts` | 失敗したツール。断られた・エラーを返したものを数える |
| `› 構成を調べます` | サブエージェントの発言の最初の行 |
| `ツール 8 · 失敗 1` | ツールの回数と、失敗の数 |
| `━━━━━━━━━━` と `Read 5 · Bash 2 · Edit 1` | ツールの内訳。割合の棒と名前を、ツールごとの色で出す。多い順に 3 つまで出し、残りは「ほか」にまとめる。2 回から出す |
| `Σ 合計 4 体 · in 210k · out 12k · ツール 24` | メインとサブエージェントを足した合計。サブエージェントがいる間だけ出す |
| `会話を要約しています…` | 会話の要約（compact）が動いている |

pane の幅が 42 桁以上あれば、カードをアイコンと同じ色の丸い枠で囲む。止まっているカードの枠は薄くする。

ツールの対象は、ファイルなら親のフォルダまで、`Read` なら読む行の範囲、`Grep` なら探す場所まで出す。MCP のツールは、最初の文字の引数を出す。

## 🖥️ アイコン

Claude Code の起動画面のロゴを 9 桁 × 3 行で描き、その頭の上の 1 行に、作業に合わせた小道具を描く。動いている間は 100ms ごとに描き替える。

| 状態 | 色 | 動き |
| --- | --- | --- |
| メインが作業中 | ロゴの色。上の行を明るく、下の行を暗くする | 下の表の、作業に合わせた動き。白い光の帯が左上から右下へ流れる |
| メインが待っている | 灰 | 止まる。頭の上に `zZ` を出す。ターンが終われば `✓`、エラーなら `✗` |
| サブエージェントが動いている | 起こした順に青・緑・ピンク・紫・水色 | メインと同じく回す |
| サブエージェントが終わった | その色のまま | 止まる。頭の上に `✓` を出す |
| 失敗・停止した | 赤 | 止まる。頭の上に `✗` を出す |

動いている間の動きは、最後に始めたツールで決まる。

| 作業 | 動き |
| --- | --- |
| `Bash`・`Edit`・`Write`・`NotebookEdit` | パソコンを打つ。腕を交互に下ろし、頭の上に打った字が伸びる |
| `Read`・`Grep`・`Glob` | 書類を目で追う。頭の上の行の、読んでいる所が左から右へ動く |
| `WebFetch`・`WebSearch` | 頭の上で地球儀が回り、両脇に波が出る |
| サブエージェントを待っている | サッカーのヘディング。落ちてきたボールを、かがんで待ち、跳んで頭で打ち上げる |
| 動いているツールが無い | 考える。頭の上に泡が浮かんで大きくなり、`?` が `!` に替わる |
| そのほかのツール | 立つ・かがむを繰り返し、頭の上がきらめく |
