# ios-snapshot-gallery

`make snapshot` で描いた PNG を、直す前と後で並べたページにして、ブラウザーで開くプラグイン。

## ✨ 機能

| できること | 中身 |
| --- | --- |
| 前の画像を取っておく | 描く前に、セットの画像を前のフォルダへ写す。コマンドが失敗した時は、前のフォルダをそのままにする |
| 一覧のページ | 描くたびに、出力先に `index.html` を書く。画像を画面ごとにまとめ、変更・新規・同じを色で分ける |
| 知らせる | 描き終えたら、変更・新規・同じ・消えたの数をトーストで知らせる |
| 自動で開く | 人が見ているセッションで、変わった画像か新しい画像があれば、一覧をブラウザーで開く |
| 画面の名前 | 出力先に `index.jsonl` があれば、ファイル名の代わりに画面の名前と描き方を出す |
| 消えた画像 | 前にはあって後に無い画像を、消えたとして数えて一覧に載せる |
| 失敗を知らせる | 写し・入れ替え・ページの書き込み・ブラウザーで開くことに失敗した時は、トーストで知らせる |

## 📦 入れ方

```sh
/plugin install ios-snapshot-gallery --marketplace yossibank/claude-plugins
```

## 🚀 使い方

| 操作 | 動き |
| --- | --- |
| `/snapshots <セット>` | セットの画像を読み込んで、一覧をブラウザーで開く。セットを省くと、前に描いたものを開く |

一覧のページは、すべてクリックで操作する。

| 操作 | 動き |
| --- | --- |
| 上の数字のタイル | 要確認・変更・新規・同じ・すべて・消えたで絞り込む |
| 左の一覧 | その画面へ移る。見ている画面が光る |
| 描き方の小さな画像 | 描き方を切り替える。画像の高さは、選んだ画像が横幅と窓に収まる大きさに決まる |
| 比べ方 | 並べる・スライダー・差分・後だけを切り替える。スライダーは、つまみを左右に引く |
| 確認済みにする | 画面を確認済みにし、右上の進みに数える。ブラウザーが覚える |
| 画像を押す | 大きく開く。前と次の画面・比べ方・描き方を切り替えられる。画像の外を押すと閉じる |

[ルートの README の入れ方](../../README.md#-入れ方)

## 🔧 設定

| 名前 | 中身 |
| --- | --- |
| `commandPattern` | 見張るコマンドの正規表現で、1 つ目の組がセットの名前。壊れた時は初めの値で見張る |
| `snapshotsDir` | 描いた画像のフォルダ。基点からの相対パス |
| `beforeDir` | 描く前の画像を取っておくフォルダ。基点からの相対パス |

[既定の値](.claude-plugin/plugin.json)
