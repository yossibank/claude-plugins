# ios-snapshot-gallery

`make snapshot` で描いた PNG を、直す前と後で左右に並べて pane に出すプラグイン。

## ✨ 機能

| できること | 中身 |
| --- | --- |
| 前の画像を取っておく | 描く前に、セットの画像を前のフォルダへ写す。コマンドが失敗した時は、前のフォルダをそのままにする |
| 並べる | 描き終えたら、前と後を左右に並べて pane に出す |
| 見分ける | 画像ごとに、変更・同じ・新規を出す。画像の下に、描いた日時を出す |
| 全体を見る | 見出しに、1 枚を 1 文字（`●` 変更・`·` 同じ・`+` 新規）にした並びを出し、今の 1 枚を反転する |
| 大きさを比べる | 画像の下に、大きさ（px）とファイルの大きさを出す。前と違う時は、前の大きさと差も出す |
| 消えた画像 | 前にはあって後に無い画像を、削除として数えて名前を出す |
| 失敗を知らせる | 写しや入れ替えに失敗した時と、pane を開けなかった時は、トーストで知らせる |

## 📦 入れ方

```sh
/plugin install ios-snapshot-gallery --marketplace yossibank/claude-plugins
```

## 🚀 使い方

| 操作 | 動き |
| --- | --- |
| `/snapshots <セット>` | セットの画像を読み込んで pane を開く。セットを省くと、前に描いたものを開く |
| `j` | 前の画像へ移る |
| `k` | 次の画像へ移る |
| `c` | 変更のあるものだけに絞る。もう一度押すと全部に戻す |
| `o` | 後の画像を Finder で開く |

[ルートの README の入れ方](../../README.md#-入れ方)

## 🔧 設定

| 名前 | 中身 |
| --- | --- |
| `commandPattern` | 見張るコマンドの正規表現で、1 つ目の組がセットの名前。壊れた時は初めの値で見張る |
| `snapshotsDir` | 描いた画像のフォルダ。基点からの相対パス |
| `beforeDir` | 描く前の画像を取っておくフォルダ。基点からの相対パス |

[既定の値](.claude-plugin/plugin.json)
